# OXKAT image products and previews

This guide describes the file suffixes observed in OXKAT's FLAG imaging products and generated by the upstream OXKAT `setups/FLAG.py` and `setups/2GC.py` recipes. These descriptions are based on file naming and code inspection, not a validated astronomical evaluation specification. Confirm the scientific interpretation of derived primary-beam and weight-map products with the OXKAT imaging authors before using them as quality metrics.

## Reading an OXKAT filename

Example:

`img_measurement_set_1024ch_MAXIJ1348.ms_datablind-MFS-image.fits`

- `img_...MAXIJ1348.ms`: the image prefix contains the input target Measurement Set identity.
- `datablind`: the FLAG recipe's blind imaging of the Measurement Set DATA column.
- `MFS`: multi-frequency synthesis; the wideband image rather than a numbered spectral output.
- `image`: restored (deconvolved) image product.
- `.fits`: FITS data, not a display-ready preview.

Numbered identifiers such as `-0000-` ... `-0007-` denote per-channel-group outputs of the WSClean imaging run. The exact frequency interval associated with each group should be derived from FITS metadata or WSClean configuration, not guessed from its index.

## Common suffixes

| Filename suffix | Interpretation | Evaluation use |
| --- | --- | --- |
| `-MFS-image.fits` | Multi-frequency-synthesis restored image | Primary overview of detected sources and imaging artifacts |
| `-MFS-dirty.fits` | MFS dirty image, before deconvolution | Examine undeconvolved sky response and sidelobes |
| `-MFS-model.fits` | MFS deconvolution model | Inspect modeled emission, not equivalent to restored sky |
| `-MFS-residual.fits` | MFS residual image after model subtraction | Diagnose noise, sidelobes and unmodeled structure |
| `-MFS-psf.fits` | MFS point-spread function | Diagnose synthesized beam/sidelobe behavior |
| `-MFS-image.mask0.fits` | Initial cleaning mask generated during FLAG | Inspect spatial extent of regions selected for cleaning |
| `*.mask1.fits` | Refined cleaning mask generated during 2GC | Inspect stage-specific updated cleaning mask |
| `-MFS-image.pb.fits` | Primary-beam response product | Inspect primary-beam coverage; not an ordinary sky-intensity image |
| `-MFS-image.pbcor.fits` | Primary-beam-corrected image | Examine the corrected sky-intensity product; noise can increase at low beam response |
| `-MFS-image.wt.fits` | Auxiliary weight-map product | Diagnose weighting / coverage; interpretation depends on generating tool |
| `-0000-image.fits` and analogous numbered products | Restored images for WSClean channel groups | Evaluate spectral variation, when required |
| `-0000-dirty.fits`, `-0000-model.fits`, `-0000-psf.fits`, `-0000-residual.fits` | Corresponding per-channel-group products | Optional deeper inspection |

## Recommended default preview priority

For routine agent evaluation, prioritize the primary-beam-corrected MFS image when present, then the restored MFS image, MFS residual, initial/refined cleaning masks, MFS dirty image, model, PSF, primary-beam map and weight map. Use numbered channel-group images for optional deeper analysis after the main MFS outputs.

The preview generator selects a bounded number of files rather than processing every numbered product. The `image_qa.json` catalog retains the complete original source FITS name and maps it to generated PNGs, display stretches and sampled statistics.

## Important scientific caveats

- Previews are visual aids, not substitutes for original calibrated FITS data.
- The preview generator's statistics are computed from a strided sample, not necessarily all FITS pixels.
- A preview of a residual or mask must not be interpreted like a restored intensity image.
- Compared images should use comparable sky regions and explicit display scales.
- A bright-pixel-centered crop does not necessarily identify the most scientifically interesting object.
- Full per-product evaluation criteria should be reviewed with astronomers.

## Original source references

- [OXKAT `setups/FLAG.py`](https://github.com/IanHeywood/oxkat/blob/master/setups/FLAG.py): constructs the `datablind` image prefix, WSClean imaging call, initial `mask0` and primary-beam correction.
- [OXKAT `setups/2GC.py`](https://github.com/IanHeywood/oxkat/blob/master/setups/2GC.py): runs masked imaging, self-calibration imaging, refined `mask1` and primary-beam correction.
- [OXKAT CAESAR `run_oxkat.sh`](https://github.com/inaf-oact-ai/oxkat-caesar/blob/main/run_oxkat.sh): validates image/mask outputs and publishes them under `results/IMAGES`.
